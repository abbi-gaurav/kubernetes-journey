* docker command and entrypoint
** command
#+begin_src shell
  FROM ubuntu
  CMD ["sleep", "10"] #["cmd","param 1"]
#+end_src

#+begin_src shell
  FROM ubuntu
  CMD sleep 10 #cmd param 1
#+end_src
- fully gets overridden from commandline: =docker run ubuntu-sleeper sleep 10=
- or none provided =docker run ubuntu-sleeper=
** entrypoint
#+begin_src shell
  FROM ubuntu
  ENTRYPOINT ["sleep"] #["cmd"]
#+end_src
- command arguments get appended: =docker run ubuntu-sleeper 10=
** both together
#+begin_src shell
  FROM ubuntu
  ENTRYPOINT ["sleep"] #["cmd"]
  CMD ["10"] #["cmd","param 1"]
#+end_src
- default is used if none provided: =docker run ubuntu-sleeper=
- or one can provide one: =docker run ubuntu-sleeper 5=
- or override both =docker run --entrypoint sleep2.0 ubuntu-sleeper 4=
