* commands
- test nginx config
  - =nginx -t -c $(pwd)/1-nginx.conf=
- start nginx with a conf
  - =nginx -c $(pwd)/1-nginx.conf=
- check for all processes with ports
  - =sudo lsof -i -P | grep LISTEN | grep nginx=
- reload nginx config
  - =nginx -s reload -c $(pwd)/1-nginx.conf=
* concepts
** match
- a regex match has more priority than a prefix match.
|---------------------+----------|
| Match type          | modifier |
|---------------------+----------|
| Exact               | =        |
| Preferential Prefix | ^~       |
| REGEX               | ~ or ~*  |
| Prefix              | None     |
|---------------------+----------|
